# 🎹 Hand Gesture Virtual Piano

A virtual piano that can be played using hand gestures detected through a webcam. The project uses computer vision and hand-tracking to identify finger positions and trigger corresponding piano notes in real time.

## Features

- Real-time hand tracking using MediaPipe
- Webcam-based gesture recognition
- Virtual piano interface
- Audio playback for piano notes
- Simple and interactive user experience
- No physical keyboard or piano required

## Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy
- Pygame
